\chapter{Contest}

\section{Competition Script}
\begin{itemize}
	\item Over all contest:
	\begin{itemize}
		\item Code faster problems first
	\end{itemize}
	\item Start (0h-1h):
	\begin{itemize}
		\item Skim problemset
		\item Find easiest problems and rush their implementation
	\end{itemize}
	\item Early middle (1h-2h30m):
	\begin{itemize}
		\item Use "little paper" to track readings of problems
		\item Run pre-submit protocol
		\item Read all problems
		\item Code easy problems, switch coders
		\item Stay calm, patient and careful
	\end{itemize}
	\item Late middle (2h30m-4h):
	\begin{itemize}
		\item Teammates must be fed and hydrated
		\item Discuss problems between the team
		\item Choose which will be attempted (and by whom)
	\end{itemize}
	\item Freeze (4h-5h):
	\begin{itemize}
		\item Join the team to pass the next problems, one by one
	\end{itemize}
\end{itemize}

\section{Submission and Verdicts}

\subsection{Pre-submit}
\begin{itemize}
	\item Write a few simple test cases if sample is not enough.
	\item Are the time and memory limits fine?
	\item Could anything overflow?
	\item Check your I/O:
	\begin{itemize}
		\item Is fast I/O abled (including endl)?
		\item Are you reading input correctly?
		\item Is your output format correct? (including whitespace)
	\end{itemize}
\end{itemize}

\subsection{Negative Verdicts}
\begin{itemize}
	\item Print your solution file! Print some debug output, as well.
	\item Read the full problem statement (including limits) again.
	\item Have you understood the problem correctly?
	\item Do you handle all corner cases correctly?
	\item Inspect your code:
	\begin{itemize}
		\item Are you reading input correctly?
		\item Is your output format correct? (including whitespace)
		\item Are you clearing all data structures between test cases?
		\item Any uninitialized variables?
		\item Any overflows?
		\item Confusing N and M, i and j, etc.?
		\item Are you sure the STL functions you use work as you think?
	\end{itemize}
	\item See sections below.
\end{itemize}

\subsubsection{Wrong Answer}
\begin{itemize}
	\item Check your idea:
	\begin{itemize}
		\item Are you sure your algorithm works?
		\item What special cases have you not thought of?
		\item Create some testcases to run your algorithm on.
		\item Go through the algorithm for a simple case.
	\end{itemize}
	\item Go through this list again (seriously).
	\item Ask for help:
	\begin{itemize}
		\item Ask a teammate to read the problem.
		\item Explain your algorithm to a teammate.
		\item Ask the teammate to look at your code.
	\end{itemize}
	\item Take some time:
	\begin{itemize}
		\item Go for a small walk, e.g. to the toilet.
		\item Rewrite your solution from the start or let a teammate do it.
	\end{itemize}
	\item Add some assertions, maybe resubmit.
\end{itemize}

\subsubsection{Runtime Error}
\begin{itemize}
	\item Have you tested all corner cases locally?
	\item Are you using too much memory? See MLE
	\item Inspect your code further:
	\begin{itemize}
		\item Are you reading input correctly?
		\item Any uninitialized variables?
		\item Are you reading or writing outside the range of any vector?
		\item Any assertions that might fail?
		\item Any possible division by 0? (mod 0 for example)
		\item Any possible infinite recursion?
		\item Invalidated pointers or iterators?
	\end{itemize}
\end{itemize}

\subsubsection{Time Limit Exceeded}
\begin{itemize}
	\item Do you have any possible infinite loops?
	\item What is the complexity of your algorithm?
	\item Are you copying a lot of unnecessary data? (References)
	\item What do your teammates think about your algorithm?
	\item Optimize cache and instructions
\end{itemize}

\subsubsection{Memory Limit Exceeded}
\begin{itemize}
	\item What is the max amount of memory your algorithm should need?
	\item Are you clearing all data structures between test cases?
	\item Use global memory
\end{itemize}
